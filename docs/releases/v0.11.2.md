# v0.11.2 · 墨问引用卡片与关键词搜索

发布日期：2026-09-17 · 功能版 · 需求/验收 `docs/PRD-v0.11.2.md`

## 新增

### 引用笔记块展示标题（R1）

下载的墨问笔记里引用其他笔记时，正文原位置渲染**引用卡片**（标题/摘要/作者/链接），
对齐墨问客户端的内联形态——此前正文里的 `<note uuid>` 占位标签不被解析，阅读器里
「关联阅读：」后面是空白，只在文末追加一个只有 uuid 前 8 位的列表，必须点开链接才知道
引用的是什么。

- 标题经匿名 `note/show` 按引用 uuid 逐条拉取（与正文同源，无新增接口）；
- **付费子笔记如实标注**「引用付费笔记（标题不可见）」——服务端对付费内容连标题都不
  返回（400 `ASSET_NOT_FOUND`），不伪装成功；单条拉取失败 likewise 回退为失败卡片 +
  告警，不阻塞父笔记下载；
- 旧的文末「引用笔记（N 篇）」追加块退场（信息已在正文原位置出现一次）；
- Markdown 导出同步：卡片转 blockquote，标题不丢；
- 「展开引用子笔记」与标题拉取**共享同一轮请求**（同一 uuid 全程只请求一次）；
- **跨篇限速补课**：PRD-v0.11.0 承诺的「note/show 0.5s/篇」此次真正落地，且限速闸为
  进程级共享——GUI 逐篇新建请求上下文也曾让单次调用内的限速失效，现已覆盖跨篇场景；
- **图集缺图自动补齐**：`note/show` 的图片池对图集不保证完整（实测图集声明 3 张、池只
  给 2 张 URL 是常态），此前缺图只落告警；现按墨问网页端同款协议补调匿名
  `gallery/infos` 合并，池齐全不多发请求，补拉失败退回告警不炸笔记。

### 按关键词搜索墨问笔记（R2）

下载页「墨问笔记」tab 顶部新增「按用户 ｜ 按关键词」模式切换（Segmented，与全库
二级切换同构）：

- **按关键词**：全站搜笔记，结果表五列——标题（下挂摘要行）/ 作者 / 发表 / 阅读数 /
  含引用子笔记；勾选、付费默认不选、批量下载与按用户清单完全同套逻辑；
- **作者联动**：点结果里的作者名 → 切回「按用户」并直接展开该作者完整清单（搜到一篇
  好笔记 → 看他全部作品的自然续接）；切模式本身则清空结果与勾选（主动联动除外）；
- **按用户模式零行为变更**：e2e 既有断言不改动全过；
- 走 mocli 官方 OpenAPI（`notes search`），无新增逆向面；CLI `mowen search` 输出条目
  新增可选 `authorName` 字段（向后兼容）。

### 界面统一（同轮实测反馈修复）

- 下载页与订阅页四个 tab 的内容区统一为 surface 白底卡片——「墨问笔记」此前裸渲染，
  与「按链接下载」视觉割裂；
- 表格列宽固定布局，修复标题列挤压其他列（「含引用子笔记」被压成竖排）；
- 搜索结果 `public_at=0` 的条目不再显示「1970-01-01」（显示「—」）。

## 验证

- 698 项单测、GUI e2e（含墨问下载 → 阅读器引用卡片断言、图集夹具「池 2/3 补齐」
  回归钉）、lint、TypeScript 检查全绿；
- 真机验收：CatBar 笔记引用卡片 md/html 双格式落盘（仅 2 次请求）、图集笔记 3/3 图片
  落盘零告警、关键词搜索「AI 编程」作者名落位且输出向后兼容。

## 升级建议

使用墨问功能（尤其常下载含引用/图集的笔记）或需要按关键词找笔记的用户建议升级；
仅使用微信功能的用户无感知变化。

其余能力与 v0.11.1 一致，见 `docs/releases/v0.11.1.md`。
