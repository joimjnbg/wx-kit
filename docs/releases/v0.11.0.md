# v0.11.0 · 墨问接入 + 文库复制路径 + 启动检测

发布日期：2026-09-15 · 里程碑 M59–M63 · 需求/验收 `docs/PRD-v0.11.0.md`

## 新增

### 墨问笔记下载（R2）

- 下载页新增「**墨问笔记**」tab：按用户名模糊搜索作者（候选带简介，方便确认本尊）→ 按类型/
  时间/数量拉取该作者的笔记清单（默认全选）→ 勾选批量下载，格式跟随设置页。
- 「按链接下载」同时识别墨问笔记地址（`note.mowen.cn/detail/<id>` 或裸 noteId）。
- 正文走 `note/show` 匿名接口：正文 HTML、图片（w_1200 规格本地化落地，签名 URL 不入库）、
  音频嵌入、代码块与引用块均保留；付费笔记如实标注「不可匿名获取」，不做绕过。
- **合集/引用**：含引用子笔记的笔记默认渲染「引用笔记」块防信息丢失；勾选「展开引用子笔记」
  （CLI `--expand-refs`）才递归下载，深度上限 3 层，付费子笔记如实跳过。父笔记已在文库时
  勾选展开同样生效（只补子笔记）。
- 贴图类微信文章（`item_show_type=8` 新模板）自动走**浏览器渲染兜底**提取正文与图片——此前
  这类文章会静默产出只有标题的空文件。

### 墨问作者订阅（R4）

- 订阅页新增「**墨问作者**」tab（与公众号 tab 同构）：搜索作者 → 确认简介 → 订阅；行内提供
  订阅开关（暂停检查≠删除）、检查、文库入口、本轮新笔记清单（逐篇勾选下载/忽略）。
- 定时检查与公众号订阅**共用同一套设置**（频率/自动下载），两平台互不阻塞；检查记录独立留痕
  （`mowen-subscriptions.json`，历史记录已自动迁移）。
- 检查以水位比对（`publicAt`），翻清单全量判定——不存在微信侧「只见最新一篇」的限制。

### 文库复制路径（R1）

- 文库卡片右键菜单与列表操作列新增「**📋 复制路径**」——复制该篇目录绝对路径，方便粘给
  其他工具或 agent。

### 启动检测（R3）

- 每次启动自动检测 mocli 安装与认证状态；设置页「墨问集成」区块显示路径/版本并提供重新检测；
  未安装时墨问入口显示安装指引，不影响微信功能。

### CLI

- 新增命令组 `wx-kit mowen`：`import`（单篇/按作者批量，`--expand-refs` 展开合集）、`detect`、
  `search-user`、`list-user`、`list-mine`、`search`、`subscribe`、`unsubscribe`、`list`、
  `check-now`。输出契约与其他命令一致（stdout 纯 JSON），详细说明见
  `agent/wx-kit-skill/references/commands.md`。

## 修复

- 贴图类微信文章静默产出空文件（正文/图片均空且零告警）——现为渲染兜底 + 如实告警。
- 墨问订阅页与公众号 tab 的交互对齐（订阅开关/文库入口/本轮清单/检查记录弹窗等 3 轮实测反馈）。
- 墨问检查日志与微信检查日志分开存储（原共用一份 JSON，两平台定时同时触发存在并发丢条风险，
  历史记录已迁移归位）；订阅页手动下载也落检查记录。
- 微信订阅行内「本轮清单」语义保持不变：新一轮检查全部无新时清单清空，历史明细走检查记录弹窗。

## 已知边界

- 他人私密笔记不可下载（墨问按作者授权，官方通道亦不返回）。
- `note/show` 为民间逆向接口、无官方 SLA；连续失败会如实报错。付费笔记的付费墙在服务端。
- 自己写的私密笔记（`--show-atom` 通道）与 BrowserWindow 渲染兜底顺延后续版本。
- 微信侧能力边界与 v0.10.6 一致（列表接口服务端限制，见 README）。
